# lms-portal

Client portal for web and marketing agencies. Clients log in to see monthly updates, the work done for them, their website's results and health, and to send requests, messages and files and view invoices, all in one place instead of PDFs and email.

Built first for our own clients, designed multi-tenant so it can be sold to other agencies.
