# lms-portal

Client portal for web and marketing agencies. Clients log in to see their leads, results, site health and the work done for them, and to send requests, messages, files and pay invoices, all in one place instead of PDFs and email.

Built first for our own clients, designed multi-tenant so it can be sold to other agencies.
